HireTech AI 🤖

HireTech AI is an AI-powered recruitment and candidate-ranking application that helps HR teams screen CVs faster and identify suitable candidates based on job requirements.

The application allows users to upload multiple PDF or DOCX CVs, provide a job description and required keywords, and automatically analyze and rank candidates using AI.

Features
Upload multiple candidate CVs
AI-powered CV analysis using Groq
Match required keywords with CVs
Display matched and missing keywords
Analyze education, experience, skills, and certifications
Customizable scoring weightage
Rank candidates based on overall suitability
Editable job description and keywords
Export candidate results to Excel
Technology
Python
Streamlit
Groq API
Pandas
PyPDF
python-docx
OpenPyXL
How It Works
Enter or modify the job title.
Review the job description.
Add or modify required keywords.
Set the scoring weightage.
Upload candidate CVs.
Analyze the candidates.
Review rankings, matched keywords, missing keywords, and scores.
Download the recruitment report.

The application comes with a Hydrologist job description and keywords by default, but it can be customized for any job role.

Purpose

HireTech AI aims to make the initial recruitment screening process faster, more structured, and AI-assisted, helping recruiters focus their time on the most suitable candidates.
